# Dhiraj & Neha wedding invitation

Mobile-first Krishna-inspired wedding invitation with an animated envelope, custom floral artwork and a monogram wax seal.

## Local preview

Run `npm run dev`, then open http://127.0.0.1:8000.

## Vercel

Import this repository, select **Other** as the framework preset and use **dist** as the output directory. No build command is required. The included vercel.json sets the output directory.

Wedding dates and venues are sample details pending confirmation.
